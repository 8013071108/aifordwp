Subject: Copilot Update - What We Know and What To Do Next

We have reviewed the recent Copilot reports raised by Finance, HR, Sales, and support teams. In most cases, Copilot is available, but access depends on your permissions, document protection settings, and how recently content was created or shared. We know this is frustrating, and we are actively working through each case.

Please use the steps below for the issue you are seeing:

1) Copilot cannot summarize a SharePoint file you can open
- Check whether the file is marked as highly sensitive or restricted.
- If possible, try the same request on a non-sensitive test file in the same site.
- If it still fails, raise a ticket with file name, site link, and screenshot of the message.

2) New starter: Copilot in Outlook does not seem to know recent email
- Wait and retry later today as new accounts can take time to fully populate.
- Confirm you are signed in with your work account in Outlook.
- If still unchanged by next business day, raise a ticket with your start date and affected mailbox.

3) Copilot says it has no access to sensitive HR or salary files
- Confirm you can open the file directly and that access is still active.
- Check with your manager whether this content is intentionally restricted.
- If access should be allowed, raise a ticket with file name and the exact Copilot message.

4) Copilot cannot find a contract shared from another organization
- Open the contract link directly and confirm it still works.
- Ask the sender to share through your internal team location where possible.
- If you still need help, raise a ticket with the shared link and sender organization.

5) Copilot stopped working for a whole team
- Sign out and sign back in to your Microsoft 365 apps.
- Restart your laptop once and test again.
- If multiple users are affected, report through your team lead with names, time started, and apps affected.

6) Copilot summarized a file you forgot you had access to
- Review who has access to that folder and remove access if no longer needed.
- Move sensitive files to the correct restricted location if required.
- If you think access is incorrect, raise a ticket with folder path and file name.

7) Copilot gives generic answers and not internal content
- Make sure you are using your signed-in work account.
- Try asking with specific file or site names rather than broad prompts.
- If results stay generic, raise a ticket with the app used and example prompt.

8) Copilot cannot use a shared mailbox calendar
- Confirm you can open the shared calendar directly first.
- Retry from Outlook web and desktop to compare behavior.
- If still not available, raise a ticket with mailbox name, your role, and screenshots.

What to include in all tickets for faster support:
- Your username
- App used (Outlook, Teams, Word, etc.)
- Exact error message or screenshot
- Time the issue happened
- File/site/mailbox name involved

Thank you for your patience while we complete fixes and access reviews.
